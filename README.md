# HENZO — Site Biográfico

Site biográfico dark/profissional criado em HTML, CSS e JavaScript.

## Estrutura

- `index.html` — conteúdo e estrutura
- `style.css` — identidade visual, responsividade e animações
- `script.js` — menu mobile, animações e modal da galeria
- `assets/` — coloque aqui as fotos do Henzo

## Como colocar as fotos

Crie/coloque as imagens em `assets/` e substitua os blocos `.photo-placeholder` do HTML por:

```html
<img src="assets/henzo-01.jpg" alt="Henzo">
```

Para a galeria, recomendamos 3 ou 4 fotos.

## Identidade visual

Preto + azul + vermelho, estética dark, neon discreto, glassmorphism e layout responsivo.
